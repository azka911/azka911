## Featured Projects

### [HeatWatch — Urban Heat Map Dashboard](https://github.com/YOUR_USERNAME/heatwatch)
> Final Year Project · Next.js · FastAPI · PostgreSQL/PostGIS · Scikit-learn · Google Earth Engine · Mapbox GL JS

End-to-end geospatial ML system for urban microclimate awareness in Greater KL.
- Processed 1,934 MODIS satellite data points via Google Earth Engine & PostGIS
- Random Forest model: R²=0.652, MAE 1.63°C
- Identified 554 high-risk heat hotspots (LST >= 36°C) and quantified +5.18°C Urban Heat Island intensity
- Interactive 3D Mapbox dashboard with observed/predicted mode toggle across 9 land cover scenarios
